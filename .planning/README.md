# Lily Planning

This folder is the planning source of truth for Daily English Buddy.

## Files

- `PROJECT.md`: product and technical snapshot.
- `REQUIREMENTS.md`: observed requirements and constraints.
- `EXISTING-CODEBASE.md`: current architecture and important files.
- `ROADMAP.md`: practical next phases.
- `STATE.md`: current project status.
- `DECISIONS.md`: known decisions and rationale.
- `OPEN-QUESTIONS.md`: unknowns that need user or code confirmation.
- `phases/`: focused future implementation plans.

## Adoption Rules

- Facts are based on the current repository unless marked as assumptions.
- `web/` is the current live app.
- `archive/` and `internal-info/` are treated as historical unless explicitly revived.
- Product code is not changed during adoption.
